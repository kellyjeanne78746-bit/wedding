If something looks wrong — start here

SymptomFirst place to look · how to fix
Whole site is down / won't load Check status.cloudflare.com. If green, log in to Cloudflare → Pages and look at the latest deployment.
"Site is not yet configured" message Cloudflare — the SITE_PASSCODE secret isn't set. Run npx wrangler pages secret put SITE_PASSCODE
Passcode page rejects the right passcode You (or someone) rotated it. Cloudflare → Pages → Settings → reset, then tell guests the new one.
"Guest list temporarily unavailable" The GUESTS KV is empty. From Terminal: npm run deploy (re-syncs functions/guests.json).
"We couldn't find that on our guest list" Check spelling in functions/guests.json. Lookup is case-insensitive but exact on spelling.
RSVP submits OK but no confirmation email Resend — either RESEND_API_KEY isn't set as a Pages secret, or the key was revoked. Check resend.com → API Keys.
Emails arrive but land in spam Domain DNS — SPF/DKIM/DMARC records for veronicaandsam2027.com haven't been verified at Resend. Resend → Domains.
Image is broken / shows alt text The file is missing from deploy/public/ (or the filename has a typo). Check the spelling and re-deploy.
Site shows old content after a change Hard refresh (Cmd+Shift+R). If still wrong, re-run npm run deploy.
A section won't hide / hidden one won't show Open index.html, search SECTION_VISIBILITY, flip true ↔ false, then deploy.
RSVP form returns 401 Unauthorized Visitor's gate cookie expired (30 days). Tell them to refresh and re-enter the passcode.
Can't find a submitted RSVP Terminal: npx wrangler kv key list --binding=RSVPS --remote then npx wrangler kv key get --binding=RSVPS --remote <party-id>
